# Global Names Finder Dictionaries

`hashdict/dict.bin` contains all dictionaries used by gnfinder: known
genera, species epithets and other uninomials, their ambiguous variants,
ambiguous genus-species combinations, common words, and words that are
never parts of names. Every word is stored as a 64-bit hash with flags
telling which dictionaries contain it. The format is described in
`pkg/io/dict/hashdict`.

The file is generated by [gndict](https://github.com/gnames/gndict). To
update it, run gndict and copy its `dict/hashdict/dict.bin` output here.
gndict also writes the dictionaries as CSV files next to it, for reading
and comparing.
